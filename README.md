# Greek Bible Lexicon (GBL-EPV)

A Greek dictionary module for [theWord](https://www.theword.net/), keyed to Strong's numbers.

- **Module id:** jb51 · **Title:** Greek Bible Lexicon - Various Authors · **Abbreviation:** GBL-EPV
- **Numbers:** G1–G13149 (G1–G5624 standard Strong's; later numbers cover words found only in the Septuagint)
- **Content:** Thayer definitions, Liddell-Scott-Jones (LSJ) definitions, Brown-Driver-Briggs entries for proper names, NT counts (Textus Receptus, Byzantine, SBLGNT) and LXX verse lists (Rahlfs, Swete, Brenton)
- **Companion modules:** LXX Brenton+, SweteLXX+, LXX Rahlfs+ (see the LXX-Strongs-and-RMA-Codes repository)

## Download

`epv-thayer-kjv_<date>.dct.zip` contains the `.dct.twm` file. Unzip it and put it in your theWord `Modules` folder. The newest dated file is the current one.
